# Login sound

User-selected replacement for the synthesized login tone: Cyberpunk message effect.
Source page: https://www.myinstants.com/en/instant/cyberpunk-message-10645/
Download: https://www.myinstants.com/media/sounds/cyberpunk-message.mp3
Community-uploaded clip; provenance as original game audio has not been independently verified.
Converted with ffmpeg to 44.1 kHz stereo PCM16 WAV. Played at user sign-in by the installed Arasaka Audio.vbs, not during UEFI boot.
