# ARASAKA / CYBER//DECK — оформление Windows 11

Красно-чёрная тема по мотивам Cyberpunk 2077: обои Arasaka, значки, курсоры, тёмные окна, красные акценты и заставка входа. Фанатский проект, не официальный продукт CD PROJEKT RED.

## Установка в один запуск

1. Скачайте ZIP этой ветки через **Code → Download ZIP** и распакуйте целиком в обычную папку. Запуск из ZIP не поддерживается.
2. Для анимированных обоев заранее установите **Lively Wallpaper (desktop-версия с livelywallpaper.net)** или **Wallpaper Engine из Steam**. Без них установятся статические обои. Rainmeter нужен только для дополнительного HUD.
3. Установите Windhawk и перечисленные ниже моды, если нужно полное оформление окон и панелей.
4. Дважды нажмите **Install-Arasaka.cmd**. Подтвердите запрос прав администратора для настроек Windhawk. Остальные действия выполняются в текущей учётной записи.

Установщик сам выберет Lively, если он найден; иначе Wallpaper Engine; иначе статические обои. Он генерирует графику под разрешение основного экрана, ставит значки и курсоры, применяет цвета, экран блокировки и тему Windows Terminal, настраивает имеющийся движок обоев и Rainmeter. Добавляет заставку после входа и ярлыки **Arasaka - Preview / Shutdown / Restart**.

Папка установки: `%USERPROFILE%\CyberDeck`. Имя пользователя и буква диска не зашиты. Wallpaper Engine ищется во всех Steam-библиотеках. Для Rainmeter учитываются перенаправленная папка «Документы» и SkinPath из Rainmeter.ini.

Проводник перезапустится: окна папок закроются. Перезагрузка и выключение компьютера не выполняются. Закройте и снова откройте «Параметры» и быстрые настройки после установки. Первое применение некоторых значков может потребовать повторного входа.

## Моды Windhawk

| Мод | Что оформляет |
|---|---|
| [Windows 11 Start Menu Styler](https://windhawk.net/mods/windows-11-start-menu-styler) | Пуск и поиск |
| [Windows 11 File Explorer Styler](https://windhawk.net/mods/windows-11-file-explorer-styler) | Проводник и контекстные меню |
| [Windows 11 Taskbar Styler](https://windhawk.net/mods/windows-11-taskbar-styler) | Панель задач и трей |
| [Windows 11 Notification Center Styler](https://windhawk.net/mods/windows-11-notification-center-styler) | Уведомления, календарь и быстрые настройки |
| [Windows 11 Settings Styler](https://windhawk.net/mods/windows-11-settings-styler) | Приложение «Параметры» |
| Translucent Windows / существующий local@translucent-windows-fork | Дополнительное чёрное стекло Проводника; необязательно, без него используется Mica |

Программы и моды автоматически не скачиваются. При отсутствии основных модов остальные компоненты установятся, а установщик перечислит недостающие и завершится с кодом **2** («оформление окон неполное»). После их установки просто снова запустите **Install-Arasaka.cmd**: исходная резервная копия сохранится, стили применятся к новым модам. Код **0** означает завершение выбранных шагов и проверку непустых правил установленных основных модов; код **1** — ошибку.

Lively из Microsoft Store и переносные установки, которые не запущены и находятся вне стандартных путей, автоматически не определяются. Для переносной desktop-версии Lively/Rainmeter сначала запустите приложение. Статические обои доступны без этих программ.

## Параметры запуска

По умолчанию достаточно двойного щелчка. Дополнительные варианты из Windows PowerShell:

```powershell
# Только проверить окружение, без изменений
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -CheckOnly

# Выбрать движок явно
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Wallpaper Lively
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Wallpaper WallpaperEngine
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Wallpaper Static

# Пропустить дополнительный HUD или оформление Windhawk
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -SkipHud -SkipWindhawk
```

Запускайте от своего пользователя. Если запрос UAC требует пароль другой учётной записи администратора, файлы темы текущего пользователя должны быть доступны ей для чтения. Не запускайте весь установщик из чужой учётной записи.

Логи рядом с установщиком: `install.log`, `windhawk-install.log`. В них записываются ошибки и количество проверенных правил. Если Windows запретила сценарий после распаковки, используйте свойства скачанного ZIP → «Разблокировать» до распаковки, если этот пункт доступен.

## Откат

`%USERPROFILE%\CyberDeck\Restore-Windows-Look.bat` возвращает сохранённые цвета, курсоры, статические обои и настройки Terminal, отключает стилизующие моды и удаляет ярлыки Arasaka. Программы остаются установленными. Исходный `backup` не перезаписывается при повторных установках. Состояние Lively/Rainmeter до установки целиком не восстанавливается: прежние обои и скины при необходимости выберите в их интерфейсе.

Если CyberDeck уже был установлен, перед переходом на Arasaka можно дополнительно скопировать всю папку `%USERPROFILE%\CyberDeck`: исходный `backup` относится к самой первой установке темы.

## Заставки и ограничения

- Заставка входа длится 6 секунд после входа в пользовательский сеанс.
- Отдельные ярлыки Shutdown / Restart показывают отсчёт 9 секунд. Esc отменяет действие. Принудительного закрытия приложений нет.
- Preview никогда не выключает ПК. Обычная кнопка выключения Windows не запускает заставку Arasaka.
- EFI, Secure Boot, загрузчик и системные файлы установщик не изменяет. `make-boot-art.ps1` только генерирует картинку и не входит в установку.
- Некоторые встроенные глифы и значки сторонних приложений остаются стандартными. Экран блокировки зависит от политик Windows; отказ API будет записан в лог.
- Windhawk зависит от версии Windows. После обновлений проверяйте совместимость модов. Окраску общих TextBlock в трее не добавлять: ранее она вызывала падения Explorer.
- Проверка правил в реестре не заменяет визуальную проверку на конкретной сборке Windows.

Графика генерируется локально; страница живых обоев не выполняет сетевых запросов. Часы используют время Windows. Надписи корпоративной сети — художественное оформление.
## Проверки установщика

Полный запуск проверен 08.11.2026 на Windows 11 25H2 (26200), Windows PowerShell 5.1, Lively и Rainmeter. Все шаги завершились с кодом 0, исходный backup сохранился. Проверено количество непустых правил пяти основных модов Windhawk, структура 18 ICO по 8 размеров и контактный лист значков. Проверены синтаксис PowerShell и git diff --check.

`tests/Test-Installer.ps1` выполняет проверки без изменения Windows: отсутствие движков → Static, наличие только Wallpaper Engine → WallpaperEngine, наличие обоих → Lively, сообщение об отсутствующих модах.

Полная установка на чистой Windows и полный запуск ветки Wallpaper Engine в этой версии установщика отдельно не проверялись. Откат и реальный цикл перезагрузки/выключения в ходе этой проверки не запускались.

## Отдельная композиция экрана блокировки

`make-lockscreen.ps1` создаёт фон Arasaka с чистой верхней центральной зоной под системные часы. Изображение включено в генерацию `make-art.ps1` и обычную установку. Параметры `-Width` / `-Height` позволяют проверить другое разрешение; по умолчанию используется основной экран. `-Preview` создаёт отдельный lockscreen-preview.png с примером часов; эта картинка не применяется как фон. Настоящие часы, дата, вход в Windows и виджеты остаются системными.

### Дополнительный стиль живых часов (экспериментально)

В настройках Start Menu Styler добавлены XAML-правила TimeAndDatePanel / TimePanel: красные часы Bahnschrift 112 слева, светлая дата ниже. В список процессов мода добавляется LockApp.exe. Цели взяты из руководства FrostyGlass проекта Windhawk. В этой версии подтверждена запись правил; визуальный результат при блокировке ещё требует проверки. Это дополняет системные часы, а не рисует неподвижное время на фоне. LogonUI и поле PIN не меняются. make-account-picture.ps1 генерирует необязательный аватар; его нужно выбрать отдельно в настройках изображения пользователя.

### Необязательный Lock Screen Clock Styler

Если установлен lock-screen-clock-styler 0.6.x, настройка Windhawk выбирает Cyberpunk HUD, 24h, секунды, дату и батарею. Именованные XAML-элементы HUD получают правила Arasaka; прежние правила перемещения штатных часов тогда не добавляются. lockscreen-datetime-format остаётся установленным, но отключается: он форматирует скрытые штатные часы. Оба исходных набора настроек сохраняются в backup/lockscreen-mods.reg и lockscreen-format-mod.reg. Lock Screen Live Wallpaper не нужен. Фактический вид пользователь проверяет при блокировке.
