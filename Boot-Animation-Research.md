# Исследование настоящей boot-анимации — 12.11.2026

## Проверенная машина и границы

ASUS TUF Gaming A15 FA507XI_FA507XI, BIOS FA507XI.314 (CIM). Пользователь хочет движение во время загрузки Windows, не ролик после входа. На этом этапе только поиск и чтение: EFI/BCD/BIOS/системные шрифты не менялись, новых загрузчиков не установлено.

## Найденные реализации

- [AnimeBoot](https://github.com/helloyork/AnimeBoot), ревизия f1af51ce615a1c16d1cbd4f4ad2f9af73defd2c9. Исходник изучен в отдельной папке work/animeboot-review. AnimeBoot.c:454 вызывает AbPlayFromPackage, :491 восстанавливает GOP, :506 вызывает AbLaunchNextStage, :1827/:1835 LoadImage/StartImage. Следовательно, это последовательное воспроизведение ДО Windows, не параллельная анимация при загрузке ядра. docs/firmware-notes.md содержит пример лабораторного запуска и указывает, что Secure Boot в лабораторной VM выключен. Подпись описана в документации, но совместимость на данном ASUS и с FACEIT не проверена. LoopCount=0 без лимита времени не заканчивается — при будущем прототипировании обязателен конечный лимит.
- [Lenovo UEFI Logo Changer](https://github.com/chnzzh/lenovo-logo-changer): GIF и сообщения об анимации на некоторых Lenovo. Это зависимость от модели/прошивки, не готовый способ для данного ASUS. Поддержка анимации FA507XI не найдена; это результат поиска, не доказательство абсолютной невозможности.
- [Windows 7 Boot Updater](https://github.com/coderforlife/windows-7-boot-updater): настоящая замена кадров, но программа предназначена для Windows 7. Не устанавливать её в Windows 11.
- [Microsoft BGRT](https://learn.microsoft.com/en-us/windows-hardware/drivers/bringup/boot-screen-components): передаёт bitmap, не произвольный анимационный поток.
- [UEFI Boot Services](https://uefi.org/specs/UEFI/2.10/07_Services_Boot_Services.html): ExitBootServices прекращает timer services. Инженерный вывод: обычный EFI-проигрыватель нельзя просто оставить на UEFI-таймере работать до рабочего стола; нужен другой механизм отрисовки после передачи управления ОС.

## Более близкое направление: кадры штатного индикатора

Чтение C:\Windows\Boot\Fonts\segoe_slboot.ttf и segoen_slboot.ttf через fontTools подтвердило наличие private-use глифов и таблицы DSIG. Для segoe_slboot.ttf: 241 private-use glyph; просмотр первых 128 (начиная с U+E052) показал кадры вращающихся точек. Контактный лист сохранён только в work/animeboot-review/font-glyph-review.png. Файлы шрифта не копируются в репозиторий и не изменяются.

Это прямое подтверждение наличия кадров, но НЕ доказательство, что текущая сборка Windows выбирает именно эти файлы/глифы для используемого индикатора. Наличие DSIG не является проверкой действительности подписи. Замена глифов потенциально позволит изменить форму монохромного индикатора; цвет задаётся отрисовщиком и этим не решён. Рабочего проверенного метода установки на текущую Windows с Secure Boot не получено.

Следующее полезное исследование: определить реально читаемые boot-ресурсы и путь отрисовки на этой сборке, проверить требования проверки целостности, затем разработать ограниченный прототип и отдельный способ восстановления. Не обещать, что простая подмена TTF даст анимацию Arasaka. Прошивка BIOS пока не имеет обоснованного преимущества для этого требования.

## FACEIT и восстановление

[FACEIT: TPM attestation failed](https://support.faceit.com/hc/en-us/articles/20669555338268-TPM-attestation-failed) прямо запрещает самоподписанные загрузчики в проверяемой цепочке и предлагает запуск напрямую через Windows Boot Manager. Подпись для Secure Boot сама по себе не даёт совместимость с античитом. Существующий переключатель режима может исключить отдельный EFI-проигрыватель, но не откатит общие изменённые файлы Windows.

Батник в безопасном режиме достаточен только если Windows способна загрузиться в этот режим. Для сбоя до запуска ОС нужен внешний путь восстановления; существующие CMD не объявлять защитой от неудачной прошивки BIOS или любого патча winload.

Решение этапа: AnimeBoot оставить кандидатом только для отдельной предзагрузочной заставки; настоящую замену индикатора рассматривать как исследование ресурсов Windows, а не готовую установку. Систему по результатам поиска не менять.
